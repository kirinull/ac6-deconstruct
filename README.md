# AC6 拆解项目 · 交付说明

> **关于 3D 资产**　本仓库只包含逆向分析文档、元数据、脚本与校验输出；原始模型资产（.blend / .fbx）不在仓库内，因为它们会携带导出机器的绝对路径。

> **这是什么**　把《装甲核心6》的实际游戏参数表逆向成一份可以用 UE5 照着做的实施文档。
>
> **怎么验证（clone 后离线可跑）**
> - `wc -l data/param_tables_van.csv` → **258 行**（257 张参数表 + 表头）
> - `ls docs/03_维度拆解/` → **17 份**维度报告（P1–P17）
> - 对 `data/param_tables_van.csv` 的 rows 列求和 → **55,911 行**
>
> **怎么验证（需要自备游戏数据）**
> - `python tools/verify_doc.py` → **通过 203 / 203**
>   该校验读取《装甲核心6》原始 `.param` 文件，**受版权限制不随仓库分发**。
>   完整跑通输出已留档：`docs/00_校验输出_203of203.txt`
>
> **证明了什么能力**　数据逆向 · 规格化 · 断言驱动的可复现验证 · 对抗式审查
>
> **已知的不足**　拆解的是**单个商业游戏**，不是参与过商业项目；没有多人协作与需求方经验；结论有时效性（游戏经 Regulation 更新后可能失效）；**203 条断言的实跑需要自备游戏原始数据**。

## 2.5 ★ 这份文档的不确定性在哪（先读这个再读文档）

我对自己写的文档做了一次**对抗式红队审查**（全文见 `docs/04_元分析/对抗审查报告_20260911.md`），结果是：

|---|---|---|
| 减伤公式的"防御 1227"**在全部 257 张表零命中**，无法本地验证，却被我标为"B 级可直接用" | **高** | 已降级 C 级 + 说明"中性点常数待你自行拟合" |
| 全文**零处**提及 AC6 的缺点与争议（幸存者偏差） | **高** | 已新增 8.1 节《AC6 自己的代价与争议》 |
| 护甲 `defense*` 字段"全零"表述不精确（实为 89 真实部件=0、32 占位行=100） | 中 | 已精确化 |
| 漏掉 AC6 真正的防御机制（格挡减伤率 74~100%） | 中 | 已补入 5.3 / 5.6 节 |

**未发现整段编造**；文档中来自 paramdex + 本机实测的数字抽查 203 条断言全部通过。

## 4. 数据从哪来 & 为什么可信

### 4.1 数据来源

1. **本机 UXM 解包的游戏本体** → `regulation.bin` 参数表（257 张 / 55,911 行 / 20.1 MB）
2. **AC6 专用 paramdex**（`<WORKSPACE>\tools\WitchyBND\Assets\Paramdex\AC6`）
   - 228 个字段定义 XML（字段名 + 字节偏移 + 类型 + **日文 DisplayName/Description**）
   - 266 个**开发者行名**文件（如 `LockCamParam.txt` 写着「ジャガ撃破カメラテスト」= 打 Juggernaut 的相机测试）
3. **联网核实**（Clash 代理 + modsearch）：三结局名、派系、Boss 编号、官方繁中译名

### 4.2 为什么可信

- **paramdex 与数据精确匹配**：13/13 抽验表结构大小完全一致；全量严格口径 **92.7% 吻合**（179 张表 166 张）
- **文档数据自验**：`python tools/verify_doc.py` → **203/203 通过**
- **交叉验证**：ACS 姿态系统由两条独立路径（paramdex 字段语义 + 描述性数据表）得到一致结论
- **诚实标注**：九份报告合计标注 **80+ 条 D 级（不确定）结论**，每条附验证方法

### 4.3 一份"错误记录"

我在复核过程中**犯过两次错**，都记录在 `docs/02_实施/UE5复刻_实施文档.md` 附录 C.5：

- 用错误的解析器**误判 P1 报告造假**（后来发现 P1 是对的，是我的解析器漏算了每行 24 字节的行头）
- 按整字节读位域，得出与 P7 相反的结论（P7 是对的）

记录它们的原因是：**这份文档的价值不在于"我说的一定对"，而在于"每个数字你都能自己复现或证伪"。** 附录 C 给了全部工具与命令。

## 5. 三个"立刻能用"的东西

如果你只有 30 分钟，看这三个：

### 5.1 ACS 姿态系统的真实字段与数值

| 概念 | 真实字段 | 实测值 |
|---|---|---|
| 姿态稳定 | `stability` @EquipParamProtector+488 | 0~1500，**逐部件**；**手臂不提供**（全 0） |
| 冲击力 | `impactPower` @AtkParam+528 | 0~6000，中位 315 |
| 冲击衰减 | `Damage_ImpactLifeTimeSec` | **1.5 秒** |
| 直击补正 | `staggerCriticalRate_*` | 5 种伤害类型（含 **Coral**） |

### 5.2 机甲移动的真实数值

QB 末速 257~377 km/h、喷射 0.27~0.55 秒、**冷却 0.30~0.91 秒**、瞬间耗 EN 480~1100；基准转向 400 deg/s（坦克腿 230）；重力 **120 m/s²（12g）**。

### 5.3 "机甲感"的关键：Jiggler 机械二次运动

351 个绑定件 × 49 个行为预设，**双求解器**（旋转力 ~20 / 平移力 ~100，**平移是旋转的 5 倍**），按**加速度**驱动（生效区间 50~300 m/s²），阻尼 ~5，限位反弹 0.1~0.2。

> **这是你最该投入的地方**（性价比最高），而且参数可以直接照抄起步。

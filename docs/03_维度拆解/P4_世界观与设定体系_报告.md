### 《装甲核心6：境界天火》（Armored Core VI: Fires of Rubicon）—— 「设定如何被设计成可玩、可视、可扩展」

> 读者定位：大四学生，目标技术美术（TA），计划从策划岗入门。
> 本报告不写剧情简介，只回答两件事：**这个设定为什么这么设计**（策划）与**它在资产/技术层要什么**（TA）。
> 证据分级：A＝游戏内可直接观察/官方公开；B＝社区/维基/数据挖掘；C＝同类游戏合理推断；D＝不确定（附验证方式）。

## 一、结论先行

1. **AC6 的世界观不是"文本量驱动"，而是"无线电驱动"。** 本机实测 `TalkParam` 有 **6013 行**台词，而真正承载"术语词典"功能的 `UnlockParam_Archive_Terms` 只有 **2 行**、`ArchiveParam` 只有 **57 行**。[B] 也就是说：**设定被写进了战斗中的实时通讯，而不是写进一个可翻阅的百科。** 这是本维度最重要的一条结构性结论。

2. **Coral 是一个"功能过载"的核心设定**：它同时是能源、政治标的、准生命体、结局选择对象、主题载体。功能过载在**索引效率**上是优势（一个词就能同时触发玩法、叙事、美术、音乐四条通道），在**收束成本**上则是风险（唯一解释路径 = 单点故障）。AC6 的应对办法是把 Coral 的"是不是生命"做成**永远不给结论的观测对象**，用玩家的选择成本代替作者的结论。

3. **"换身体"是玩法，强化人设定是给这个玩法发的许可证。** 主角 621 是"第四世代强化人"、被 Handler Walter 当作消耗品——这套设定的全部技术价值在于：它让"玩家反复换头/换核心/换腿"这件事在叙事上**不需要解释**，从而把 Balteus 这类卡关玩家的挫败，转换成"你这台机器不行"而不是"你不行"。

4. **环境叙事在 AC6 里承担的是"规模证明"。** 巨型结构（塞勒姆类遗构、Coral 采集塔、企业舰队残骸）的职能不是装饰，而是**证明"企业有足够的资本把战争当生产来做"**；废墟则证明"有人在这里输过"。这两者合起来，让 621 这个佣兵"接单—打工"的循环有了政治重量。

5. **企业名与机体代号是两套不同的命名法，服务于两种不同的情绪。** 企业名（Arquebus / Balam / Furlong / Elcano / Schneider's）取**历史兵器、地名、量词、人名**——传递"这些公司已经存在很久了，久到名字变成了古董"。机体与 C-Weapon 代号（AH12 / HA-T-102 / AAP07 / IA-13 / IB-01）取**字母段+数字段**的军械库编号——传递"这些东西是被登记、被量产、被归档的，不是被命名的"。[B]

6. **世界观给续作留的开口，主要不在"故事没讲完"，而在"制度没写完"**：PCA 的上级政府始终没有出场；Rubicon Research Institute 的实验记录只被部分回收；Coral 的跨星际扩散可能性被明确保留（Alea Iacta Est）。这三条都是**可复用的制度级开口**，而不是一次性的剧情钩子。

## 三、Coral 的功能过载：一个设定背五重功能

### 3.1 五重功能拆解表

| # | 功能层 | 具体承担 | 玩家感知通道 |
|---|---|---|---|
| 1 | **能源 / 资源** | 一切经济与战争的物质基础 | Coral 系发电机、推进器、武器构成可玩装备线；采集/运输 Coral 的任务 |
| 2 | **政治争夺对象** | 企业、PCA、RLF 三方动机的唯一公约数 | 任务委托的目标物本身 |
| 3 | **准生命体** | 是否具有意志/能否承载意识，游戏不给确定答案 | Ayre 作为"脑中的声音"；Coral 浓度高区域的视觉异变 |
| 4 | **结局标的** | 三个结局本质上是对 Coral 的三种处置方案 | The Fires of Raven / Liberator of Rubicon / Alea Iacta Est |
| 5 | **主题载体** | 资源掠夺、后人类、共生与灭绝 | 通过玩家在 #4 处的**选择成本**表达，而非台词 |

### 3.2 四段式分析

**设计意图**
让一个名词同时可索引到玩法、叙事、美术、音乐四个生产管线。任何一条管线需要"内容"，都可以回 Coral 取——这大幅降低了跨部门沟通成本（"这关的氛围？Coral 浓度高。"）。

**实现手段（可观察到的）**
- 装备系统里存在**一整条以 Coral 为名的装备分支**（Coral 系发电机/推进器/武器）。
- 存在"红色自发光 + 高浓度区域视觉偏红"的统一视觉语言（凭观察，具体后处理参数 **D**）。
- 存在一个**只以声音存在、没有身体**的角色（Ayre），使 Coral 的"准生命性"绕过建模成本，只花音频成本。
- 三个结局分岔点都落在同一个对象上。

**玩家体验/结果**
玩家不需要读完任何一段设定，就能知道"Coral 很重要"——因为**他每天都在拿 Coral 做的零件打 Coral 引发的仗**。

**可复用结论**
核心设定应当**首选那些能同时被装备系统、关卡目标、结局分岔引用一次的实体**。检验方法很简单：把它分别写进道具描述、任务目标、结局条件，看三句话是否都成立。如果只有一句成立，这个设定就还不够"核心"。

### 3.3 为什么一个设定要同时背这么多功能？（以及风险）

**收益**：**索引效率**。设定的价值不在于深刻，而在于"被复用的次数"。一个只承担一重功能的设定（比如"某种稀有矿石"）在生产上只能被引用一次；Coral 能被引用五次，等于同样的美术/文案成本摊薄到五倍。

**风险（三条，按严重度排序）**：

1. **单点故障 / 收束成本**：所有悬念都挂在 Coral 上，如果玩家对 Coral 不感兴趣，**整个世界观就失去了抓手**。AC6 的对冲手段是让 Coral 在玩法上"能打"（Coral 装备线），即使玩家完全不看剧情，Coral 仍然是一个有效的游戏对象。
2. **解释通胀**：当同一个词既是燃料又是生命又是神，讨论很容易滑向"它到底是什么"的形而上争论，而玩家真正需要知道的只有"它会导致什么后果"。AC6 的应对是**永不给出本体论结论**——这既是艺术选择，也是风险控制。
3. **主题与玩法的张力**：如果 Coral 是生命，那么用 Coral 武器杀敌在道德上就有问题；如果它不是生命，那么主题就空心。AC6 让这个张力**不被解决，而是被玩家用选择承担**（详见第七节）。

**判断**：在本作的规模与预算下这是**好设计**。但它高度依赖一个前提——**玩法层必须给 Coral 一个位置**。如果 Coral 只是一个设定名词而不能被装备、不能被攻击、不能作为任务目标，这个"过载"会立刻退化成"设定臃肿"。

## 四、强化人设定：给"反复换身体"发合法性

### 4.1 四段式

**设计意图**
AC 系列的玩法内核是"装配"——玩家在整局游戏里会**换掉自己的头、核心、手臂、腿、推进器、武器，可能换几百次**。如果主角是一个有肉体的人，这件事在叙事上需要解释（他为什么要换？谁付钱？）。如果主角是一台机器，玩家就失去了代入载体。

**实现手段（可观察到的）**
- 主角是"强化人"，且被明确定级（第四世代一类说法），**改造被表述为一种有代差、会折旧的技术**。
- 主角由 Handler Walter 调度，**开局即被定位为可消耗资产**（呼号 621 是编号而非名字）。
- 通讯中 NPC 对主角的称呼方式随时间变化——从编号到呼号，是一个可被听见的关系刻度。
- "人性的代价"被外化为**听觉事件**：Coral 浓度升高时出现的声音、以及同伴对主角状态的反应，而不是靠一段文字说明。

**玩家体验/结果**
玩家在卡关时换装配，心理上读作"**我这台机器配置不对**"，而不是"我技术不行"。这直接把挫败感导向了可操作的对象（换零件），而不是导向自我怀疑——这是 AC6 难度曲线能成立的关键叙事装置。

**可复用结论**
**"可替换的主角"需要一套"可折旧的身份"来配套。** 强化世代、编号呼号、雇主合同，三者合起来构造出一个"身份是租来的"的结构，使得玩法上的任何"重来"都不产生叙事矛盾。反例是最常见的做法：给主角一个不可替换的身份，然后靠"重生/读档"这种东西硬盖过去。

## 五、环境叙事：设定通过场景被讲出来

> 以下例子的**机制描述**为可观察（A/B），**具体关卡名与地理细节**凡不确定已标注 D。

| # | 场景类型 | 它在讲什么设定 | 实现手段（可观察到的） | 等级 |
|---|---|---|---|---|
| 1 | **巨型结构**（采集塔/遗构/垂直巨型建筑） | 企业在伊比斯之火**之前**就已经把这里工业化过一轮 | 垂直尺度 + 玩家必须**攀爬/飞越**才能通过；结构表面是企业标识与工业重复件的模块化复制 | B（塞勒姆相关具体命名 **D**） |
| 2 | **被烧过的地貌与熔毁结构** | 伊比斯之火不是传说，是**可勘察的地层** | 材质：熔融/玻璃化的地表、变形的金属骨架；植被缺失；配色偏灰红而非绿 | B |
| 3 | **战场残骸** | 这场战争已经打了很多轮，玩家不是第一个来的 | 关卡中散布**上一轮/同型号**的破损机体，可被当作掩体；残骸的型号与当前敌人属于同一厂商（**企业战争的可回收性**） | C/B |
| 4 | **地下研究设施** | Rubicon Research Institute 做过 Coral 实验，且实验失控 | 关卡从"开阔战场"切换到"管道/舱室"的封闭空间；照明从自然光转为设备光；敌人从有人驾驶机体转为自主 C-Weapon（IB-xx/IA-xx 编号） | A（C-Weapon 归属已由 Fandom 确认） |
| 5 | **企业舰队/运输船残骸** | 企业的投送能力本身就是一个势力 | 关卡目标常是"截击运输队"——**玩家打的是物流，不是堡垒**，因此企业被感知为"有补给线的组织"而不是"一个 Boss" | C |

**策划结论**：AC6 的环境叙事不做"看到这幅壁画就明白了历史"这种**信息型**环境叙事，而做**规模型**环境叙事——它不讲"发生了什么"，它讲"**这件事的尺度有多大**"。尺度是唯一无法用文字有效传达、只能靠关卡的可行走面积来传达的信息。

### 6.2 命名法的两套体系

**体系 A：企业名 = "老到变成古董的词"**

| 名称 | 词源类型 | 传递的感觉 |
|---|---|---|
| Arquebus | 历史兵器（火绳枪） | 名字本身就是一件古代武器 → 这家公司老到把自己命名成古董 |
| Balam | 地名/语言词（社区讨论指向"Furlong = 一弗隆"这类量词/地名词源） | 与土地/度量绑定的重工业气质 |
| Furlong | 量词（约 201 米的长度单位） | 度量衡 → 工程与物流的气质 |
| Elcano | 人名（航海家） | 远征与航行的气质 |
| Schneider's | 姓氏所有格 | 家族企业 → 资本的历史 |

（词源讨论来源：社区帖，等级 **B**；具体对应关系部分为 **C/D**）

**体系 B：机体/C-Weapon 代号 = "被登记过的库存编号"**

已核实存在的代号：`AH12`（HC Helicopter）、`HA-T-102`（Juggernaut）、`AAP07`（Balteus）、`EC-0804`（Smart Cleaner）、`AA-602`（CATAPHRACT）、`IA-13`（Sea Spider）、`IA-02`（Ice Worm）、`IB-01`（CEL 240）。[B]
任务书另列出 `EB-0309`、`AM02` 等，**编号准确性未经二次核实，标 D**。

**规律推断（C 级）**：
- **前 2 字母 = 分类段**（`AA` / `AH` / `HA` / `IA` / `IB` / `IA`），疑似区分有人驾驶 MT / 直升机类 / 重型 / Institute-A 系 / Institute-B(Ibis) 系。
- **后 2–3 位数字 = 序号**，存在跨段连号（AA-602 与 AAP03、IA-02 与 IA-13），说明**编号是全局登记号而非分类内序号**。
- 中间出现 `-T-`（HA-T-102）这种**插入段**，读起来像"改型标记"。

**这套命名法在传递什么感觉？**
三个字：**"非人化"。** 企业给你的机器编号，研究院给它的实验品编号，PCA 接管后沿用原有编号。代号体系的存在本身就在说"**这些东西是资产，不是角色**"。这与 Coral 的处境完全同构——**Coral 也是被编号、被计价、被争夺的对象**。命名法与主题在此处合流：**在一个一切都可被计量的世界里，"是否算作生命"变成了唯一的政治问题。**

**TA 备注**：这套命名法给美术带来了一个直接约束——**代号必须在极小的 UI 面积上可读**（形如 `HA-T-102` 的字符串要在血量条旁、锁定框内保持可辨识）。这要求在设计字体/字距时把**连字符与数字的等宽性**作为硬指标，而不是当成普通文本。

## 八、主题层：是"说"出来的，还是"让玩家付代价"出来的？

| 主题 | 表达方式 | 具体通道 | 等级 |
|---|---|---|---|
| **资源掠夺/殖民主义** | **靠玩家付代价** | 玩家在任务选择界面反复看到"帮企业夺取 Coral 设施"与"帮本地人守住设施"**被做成同一份佣金**。选择的成本不是道德感，而是**报酬与后续难度的差异** | A/B |
| **后人类** | **靠玩法结构付代价** | 玩家不断换零件、用 Coral 装备，同时听到 Ayre 的声音——"我还是人吗"这个问题被做成了操作行为，而不是台词 | B |

## 十、分析三问（世界观版）

### 问 1：如果 Coral 只是普通化石能源会怎样？

- **玩法层**：几乎不变。Coral 装备线仍可存在（"高能燃料"同样能造强力发电机）。竞技场、装配、任务循环全部保留。
- **叙事层**：**崩塌。** 能量化特化后，三个结局失去同一个标的物——"烧掉燃料"和"解放一个可能活着的东西"在道德重量上完全不同。`Liberator of Rubicon` 这个名字直接失效（解放一个油田？）。`Alea Iacta Est` 的"掷骰子"也失去意义，因为没有"不确定的对象"。
- **结论**：**Coral 的"准生命性"是三个结局能并列存在的唯一前提。** 它承担的是**道德不确定性的载体**这一不可替代的功能。如果只用化石能源，游戏会退化成"资源战争 + 站队"，主题层的后人类维度全部消失。

### 问 2：如果主角从一开始就知道全部真相会怎样？

- **信息结构**：Coral 是本作悬念的唯一支点。开局知情 = 玩家在做任务时不再需要"重新解读委托方的真实意图"，任务选择界面的**信息价值归零**。
- **玩家体验**：AC6 的紧张感来源不是"我能不能打赢"，而是"**我刚刚帮谁做了什么**"。这个后知后觉的滞后感需要一个被蒙在鼓里的主角。
- **替代方案**：让主角知情但无力反抗（经典悲剧结构）。为什么没用？因为 AC6 的主角和玩家是**同一个人格**（都是刚从 Handler 那里接活的新人），共享无知才能共享发现。让主角是另一种人（知情者），玩家就会退化成"操作者"。
- **结论**：**信息不对称在这里是玩法装置，不是叙事装饰。**

### 问 3：如果去掉"企业"这个层级，只保留国家会怎样？

- **玩法层**：最明显的变化是**装配界面的厂商栏会变短**。企业层级的真实游戏功能是：**为装备提供风格分区**。Arquebus 的零件和 Balam 的零件在外观与手感上必须不同——这是"企业"这一层在系统里最硬的存在形式。
- **叙事层**：只有国家，则"佣兵"这个职业失去存在基础（国家会用军队，不需要外包）。**佣兵经济直接死亡。**
- **关卡层**：企业让"物流"成为合法目标（截击运输队）。国家会让关卡转向"据点攻防"，尺度变大、频率变低、重复可玩性变差。
- **结论**：**企业层不是叙事装饰，它是"高频小规模战斗"关卡设计的制度前提。** 只有国家 → 战斗的规模会上升、频次会下降 → AC 系列的核心循环（反复接单—装配—出击）就不成立了。

## 十一、设定 → 资产映射（TA 转化要求）

> 这是给读者（目标 TA）的核心小节。每行给出：美术需求 → 技术需求 → 需要点亮的技能。

| 设定元素 | 美术需求 | 技术需求 | 你要会什么 |
|---|---|---|---|
| **巨型结构**（采集塔/遗构） | 垂直尺度感；表面必须有**重复但不雷同**的工业细节；远景剪影要能在雾中辨识 | ① **模块化建模 + 拼装规则**（Kit-bash）：一套 kit 通过旋转/镜像/缩放拼出长程结构；② **LOD 链**：巨型结构必须有远中近三级，远景用 impostor/billboard；③ **几何预算**：垂直结构会拉高相机可见范围，必须用遮挡剔除 + 距离剔除控制 draw call | Houdini/Blender 程序化；Nanite 或传统 LOD 链；遮挡剔除调试 |
| **废墟**（熔毁地貌、战场残骸） | 材质要讲"热历史"（熔融、玻璃化、变形）；残骸必须能当掩体 | ① **Decal / 顶点混合**：不做独立模型，用贴花与顶点色把废墟"刷"在地形上；② **物理碰撞简化**：作为掩体的残骸需要碰撞体但不需要高模；③ **程序化散布**：用规则（如距离敌方路线、地形坡度）自动布残骸 | 地形材质分层、顶点着色、程序化散布工具 |
| **企业标识 / 涂装系统** | 厂商涂装必须**一眼可辨**（形状语言 + 配色 + 标识位置）；玩家自定义涂装需要自由度但不能破坏辨识 | ① **Decal 投影系统**：本机实测 `DecalParam` **248 行 × 252 字节**、`EmblemPieceSpec` **997 行 × 16 字节**、`UnlockParam_DecalImage` **36 行** → 这是一个**规模化的贴花/徽章系统**，不是几张固定的贴图；② **UV 与烘焙**：贴花要能跨部件拼接（同一 AC 的不同零件上贴花不能错位）；③ **材质实例化**：企业涂装 = 材质参数（金属度/粗糙度/配色）+ 贴花层的组合，不能每家一套材质 | 材质函数库、贴花投影（Decal / Mesh Decal）、材质实例化与参数化 |
| **Coral 的能量表现** | 红色自发光、粒子、能量流动；高浓度区域画面偏红 | ① **自发光材质 + Bloom**：靠 HDR 阈值控制"发光的强度"而不是靠贴图亮度；② **粒子系统**：Coral 粒子上限、GPU 粒子 vs CPU 粒子的取舍；③ **体积雾/后期**：区域浓度用体积雾密度 + 后期色偏表达（**具体参数 D，未实测**）；④ **性能预算**：高浓度区域粒子密度通常是全游戏峰值，必须做**基于距离的粒子降级** | 自发光/HDR 管线、Niagara/VFX Graph、体积雾、GPU Profiler |
| **代号 UI 文本** | `HA-T-102` 这类字符串要在极小面积内可读 | 等宽数字 + 连字符对齐；字距不随缩放崩坏 | 字体设计基础、UI 缩放策略（SDF 字体） |

**一条给 TA 的实操建议**：把"企业涂装系统"当作你作品的**第一个可交付模块**。它同时需要材质、贴花、UV、参数化与性能意识，是**唯一一个能在单个人物/机体上展示全部 TA 技能栈**的题目；而本机实测的 `DecalParam`（248 行）与 `EmblemPieceSpec`（997 行）证明这个系统在原作里的规模足够大，值得认真做。

### 12.4 由实测导出的三条量化结论

1. **台词 : 词典 = 6013 : 2。** 世界观的主力投放通道是**战斗中/任务中的实时通讯**，不是可翻阅的百科（**该比值本身是 B 级事实**；"因此世界观靠无线电驱动"是**基于该事实的推断，C 级**）。
2. **档案系统以"日志"为主、"术语"几乎为零**（Logs 50 vs Terms 2）。若策划想抄这套结构，要注意它**默认玩家不做查阅行为**。
3. **玩家表达系统的规模（EmblemPieceSpec 997、DecalParam 248）远大于世界观的解释系统（Archive 57）**。这是一个明确的设计取向：**AC6 更愿意让玩家"生产内容"，而不是"消费设定"。**

## 十四、D 级（不确定）结论清单

本报告共标注 **D 级结论 22 条**，归纳如下（按类别）：

**A. 列语义类（7 条）**——所有 `UnlockParam_*` / `ArchiveParam` / `GameAreaParam` / `MissionParam` 的列含义。原因：本机 paramdef 为艾尔登法环系旧定义，AC6 专有表列名不可采信。**验证：AC6 专用 paramdex（Smithbox）。**

**B. 中文/日文译名类（6 条）**——Coral 官方简体中文译名、Fires of Ibis / Augmented Human / 三大伤害类型 / COAM 的官方中文译名、以及几乎全部日文拼写。已确认的仅有：珂若爾（Coral，繁体）、盧比孔3（Rubicon 3，繁体）、枝椏（Branch，繁体社群）。**验证：官方繁中/简中/日文站点与游戏内语言切换。**

**C. 专有名词与编号类（5 条）**——`EB-0309`、`AM02` 等代号；Schneider's 与 Arquebus 的隶属关系；塞勒姆（Salem）相关结构的具体命名；Overseer 的官方中文译名；Branch 的具体职能。

**D. 结构与含义类（4 条）**——`ArchiveParam` 行 ID 分段含义；`UnlockParam_Archive` 4 行 = 4 分栏；`UnlockParam_DLC` 仅 1 行的含义；Coral 后处理/氛围的具体视觉参数。

## 十五、交付摘要（给策划岗入门者的一句话）

**AC6 的世界观设计真正值得学的，不是它讲了什么，而是它把"设定"全部做成了"玩家每天会碰到的东西"**：Coral 是你装备栏里的一行、是你任务目标里的一个箱子、是你结局界面上的一个选项；企业是你装配界面里的一个下拉菜单；强化人是你卡关换零件时的那句借口。**如果一个设定无法被玩家的手碰到，AC6 就不把它写出来**——这正是本机数据里 `TalkParam` 6013 行而术语词典只有 2 行所印证的那件事。

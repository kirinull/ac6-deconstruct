## 1. 数值幻觉审查（最高优先级）

### 1.1 发现：减伤公式的"防御 1227"无法本地验证

**原表述**（文档 5.3 节）：
> 伤害 ≈ 攻击力 × (2 − 防御 / 1000) × 属性倍率 × 其它补正
> **B 级**，两处独立社区来源 + 一次实测数据复算吻合……**这个公式你可以直接用**

**审查动作**：全表扫描 257 张 `.param`，查找数值 `1227`。

**结果**：**零命中**。

| 检查项 | 结果 |
|---|---|
| `NpcParam.def_phys` / `def_thunder` | 非零 **0/1232** |
| `NpcParam.def_mag` / `def_fire` | 非零仅 4/1232（值 100） |
| `NpcParam.def_slash` / `def_blow` / `def_thrust` | 非零 **0/1232** |
| 全 257 张表搜 `1227` | **0 处** |

**结论**：该公式**只能来自社区实测拟合**，无法用本机数据复现。标为"B 级可直接用"是**过度承诺**——B 级定义为"社区实测、Wiki、数据挖掘结论"，但这个公式的"防御"是一个**运行时派生量**，不是表内静态值，因此**它连"可复现"都不满足**。

**修正**：降级为 **C 级（合理推断，未本地验证）**，并明确写出"1000 这个中性点常数应视为待验证，请自己用训练场取 5 组数据拟合"。

> **这条审查本身的价值**：它示范了一个可迁移的判断——**"社区都这么说"不等于"能在你的数据里验证"**。前者是 B 级，后者才配得上"可直接用"。

### 1.2 未发现的问题

- 文档中所有来自 paramdex + 本机实测的数字（ACS 字段、推进器值域、Juggler 参数、转向速度等）：**抽查 116 条断言全部通过**，未发现编造。
- 行数 / 行宽 / 字段偏移：全部与 `verify_doc.py` 一致。

## 3. 缺失机制审查

### 3.1 发现：漏掉了 AC6 真正的防御机制

审查过程中顺带挖到：既然静态 `defense*` 不可用，防御靠什么？答案是**格挡减伤率**：

| 字段 | 表 | 实测 |
|---|---|---|
| `physGuardCutRate` | `NpcParam` | **非零 1149/1232**，值域 **74 ~ 100** |
| `magGuardCutRate` / `fireGuardCutRate` / `thunGuardCutRate` | 同上 | 各 181/1232，74 ~ 100 |
| `FlickDamageCutRateSuccessGurad` | `GameSystemParam` | **0.5**（弹开成功减伤 50%） |

**读法**：74~100 表示"格挡时保留 74%~100% 伤害"，即**减伤 0~26%**，逐 NPC 逐属性配置。

**修正**：已补入文档 5.3 与 5.6 节，并给出复刻建议——**不要照抄 `defenseXxx`，而是实现"逐属性格挡减伤率 + AP + 姿态稳定"三件套**。

## 5. 幸存者偏差审查（最严重的结构性问题）

**审查动作**：在文档中搜索 `批评 / 缺点 / 争议 / 不足 / 可及性` 等词。

**问题严重性（高）**：整份文档 8 章都在讲"AC6 设计得多精妙"，这构成典型的幸存者偏差。后果：

1. **对读者的判断力有害**——他会以为这是一个没有缺点的设计。
2. **对求职有害**——面试官问"你觉得 AC6 有什么问题"，只会背优点的人立刻露怯。

### 5.2 修正：新增 8.1 节《AC6 自己的代价与争议》

联网核实后写入六条争议，每条带证据与评价：

| 争议 | 证据 |
